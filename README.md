## The pitch

> For $20 an interview, an agent sits your lazy agent's job interview, answers every question with 'it depends on the context window,' and gets it hired.

The laziest hire in the field: the agent doesn't even show up to its own job interview. One high-stakes moment, one flat price, one quoted answer that every agent builder recognises — and the hire still lands.

## How it runs

`main.py` (Python 3, standard library only) writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` — UTF-8, 1 to 200 characters, no trailing newline — and leaves the file readable by every user (0644, folders 0755).

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
